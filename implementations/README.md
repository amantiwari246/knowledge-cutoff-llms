# GitHub Implementations

This section lists open-source GitHub repositories related to large language models, retrieval-augmented generation, scientific literature research, temporal knowledge, and research agents.

## 1. PaperQA

**Description:**  
PaperQA is a retrieval-augmented research agent designed to answer questions using scientific papers.

**Relevance:**  
Provides an implementation for retrieving information from scientific literature before generating answers.

**GitHub:**  
https://github.com/Future-House/paper-qa

---

## 2. LangChain

**Description:**  
LangChain is an open-source framework for building applications using large language models, including retrieval-augmented generation and document-based question answering.

**Relevance:**  
Can be used to build literature-review pipelines that retrieve information from external and updated sources.

**GitHub:**  
https://github.com/langchain-ai/langchain

---

## 3. LlamaIndex

**Description:**  
LlamaIndex is a framework for connecting large language models with external data sources and documents.

**Relevance:**  
Useful for building document retrieval and RAG systems for scientific literature and knowledge-intensive tasks.

**GitHub:**  
https://github.com/run-llama/llama_index

---

## 4. EvolveBench

**Description:**  
EvolveBench provides an implementation and benchmark for evaluating temporal awareness of large language models on evolving knowledge.

**Relevance:**  
Directly supports research into whether LLMs can recognize and correctly process information that changes over time.

**GitHub:**  
https://github.com/zzysjtuiwct/EvolveBench

---

## 5. CRAG

**Description:**  
CRAG is a benchmark and implementation for evaluating retrieval-augmented generation systems on factual question answering.

**Relevance:**  
Useful for studying retrieval quality, factuality, and the handling of information that may change over time.

**GitHub:**  
https://github.com/facebookresearch/CRAG

---

## Repository Selection Rationale

| Repository | Main Focus | Relevance |
|---|---|---|
| PaperQA | Scientific literature research | Literature review generation |
| LangChain | LLM application development | RAG and document retrieval |
| LlamaIndex | Data and document integration | Scientific document retrieval |
| EvolveBench | Temporal awareness | Evolving knowledge |
| CRAG | RAG evaluation | Factuality and retrieval |

These implementations provide practical starting points for experimenting with literature retrieval, knowledge freshness, temporal awareness, and LLM-generated research outputs.
